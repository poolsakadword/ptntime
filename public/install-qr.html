PTN Time Attendant

ระบบบันทึกเวลาทำงานและสวัสดิการพนักงานออนไลน์

🏢 บริษัท พีทีเอ็น ฟาร์มาเซ็นเตอร์ จำกัด

สแกน QR Code เพื่อติดตั้งแอปพลิเคชันลงบนมือถือ

ติดตั้งลงหน้าจอโฮมได้ทันที สะดวก รวดเร็ว ลงเวลาได้ทุกวันโดยไม่ต้องเปิดผ่านลิงก์

สำหรับ iPhone / iPad (iOS)
https://ptntime.pages.dev/guide.html?os=ios
🍏 3 ขั้นตอนติดตั้งบน iPhone:
  1. เปิด แอปกล้อง สแกน QR Code ด้านบน (เปิดด้วย Safari)
  2. กดปุ่ม "แชร์" (Share ⬆️) ที่แถบเมนูด้านล่าง
  3. เลื่อนลงแล้วเลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen) ➔ กด "เพิ่ม" (Add)
⚠️ ต้องเปิดผ่าน Safari เท่านั้น (หากเปิดจาก LINE ให้กดจุด 3 จุด ➔ เปิดด้วย Safari)
🤖 สำหรับมือถือ Android (ทุกยี่ห้อ)
https://ptntime.pages.dev/guide.html?os=android
🤖 3 ขั้นตอนติดตั้งบน Android:
  1. เปิด แอปกล้อง หรือ Google Chrome สแกน QR Code ด้านบน
  2. แตะปุ่ม จุด 3 จุด (⋮) ที่มุมบนขวาของหน้าจอ
  3. เลือก "ติดตั้งแอป" (Install) หรือ "เพิ่มลงในหน้าจอหลัก" ➔ กดยืนยัน
✨ รองรับทั้ง Samsung, Xiaomi, OPPO, Vivo, Realme, Huawei และมือถือ Android ทุกรุ่น
💡 ข้อดีของการติดตั้งเป็นแอป (Progressive Web App):
• ไม่ต้องโหลดผ่าน Play Store / App Store • ขนาดไฟล์เบามาก (< 5MB) ไม่หนักเครื่อง • ปลดล็อกลงเวลาง่ายดายใน 3 วินาที
